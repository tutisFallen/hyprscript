# Arch Linux + Hyprland Setup

Este repositório contém um script de automação para configurar um ambiente de terminal moderno no Arch Linux.

## Componentes Incluídos
- **Terminal:** Kitty com JetBrainsMono Nerd Font
- **Shell:** ZSH + Oh My Zsh + Spaceship Prompt
- **Editores:** Neovim (LazyVim) e Helix
- **File Manager:** Yazi
- **Utilitários:** fzf, fd, bat, ripgrep

## Como usar
1. Clone este repositório ou baixe os arquivos.
2. Dê permissão de execução ao script: `chmod +x install.sh`
3. Execute o script: `./install.sh`
4. Reinicie a sessão após a conclusão.
